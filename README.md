# BeerApp

BeerApp is a mobile beer discovery and collection application centered around an interactive world map.

## Stack

- Flutter + Dart
- Python + FastAPI
- PostgreSQL / Supabase
- Supabase Auth
- Supabase Storage
- MapLibre

## Project structure

- `mobile/` — Flutter application
- `backend/` — FastAPI backend
- `docs/` — technical documentation
- `stitch/` — visual design references
- `scripts/` — development and maintenance scripts

- `PRODUCT.md`
